# 🌱 Garden-shop

**Добро пожаловать в "Garden-shop"** — монорепозиторий, в котором живут сразу два мира:  
💻 **Frontend** на Vite + React + Redux Toolkit  
🖥 **Backend** на Express + Sequelize + SQLite

---

## 📂 Структура проекта

\`\`\`
.
├── frontend/ # интерфейс, с которым взаимодействует пользователь
├── backend/ # серверная логика, API и база данных
├── package.json
├── package-lock.json
└── .gitignore
\`\`\`

---

## 🚀 Быстрый старт

### 1️⃣ Клонируем репозиторий

\`\`\`bash
git clone https://github.com/Olhaj/Garden-shop.git
\`\`\`

> 📂 _Перейдите в папку проекта:_  
> \`\`\`bash
> cd Garden-shop
> \`\`\`

---

### 2️⃣ Устанавливаем зависимости

**Frontend:**
\`\`\`bash
cd frontend && npm install
\`\`\`

**Backend:**
\`\`\`bash
cd ../backend && npm install
\`\`\`

---

### 3️⃣ Запускаем проект

**Frontend:**
\`\`\`bash
cd frontend && npm run dev
\`\`\`
Откройте в браузере → [http://localhost:5173](http://localhost:5173)

**Backend:**
\`\`\`bash
cd backend && npm run dev
\`\`\`
Сервер → [http://localhost:3333](http://localhost:3333)

---

## 🛠 Стек технологий

**Frontend:** React 18, Redux Toolkit, Vite, CSS Modules  
**Backend:** Node.js, Express, Sequelize, SQLite  
**Прочее:** Git + GitHub, .env
